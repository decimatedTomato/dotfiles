# DOTFILES

## HOW TO
- Clone this repository
- Back up any dotfiles
- Run setup.sh

## CONTAINS
- Handles 5 different common setups
	1. Linux
	2. Linux (accessed remotely through a mac)
	3. OS X
	4. WSL
	5. MSYS
- Sets similar configuration for basic tools
	1. Bash
	2. Tmux
	3. Git
	4. Vim
	5. Neovim
	6. Zsh
